## Tools

## Step
1. <b>Data Connection:</b> First, we connect to our data source or database and perform data ETL or ELT with the aid of SQL to MS Excel.
2.	Data Cleaning: In this step, we identify features of interest, deal with missing data points, perform data quality checks and populated the ‘Orders’ table with entries from the ‘Customer’ and ‘Products’ table.
3.	Dashboarding/Insight Generation: In this step, we visualized some KPIs of the business from the data in order to generate insights and have an overview of the business performance.
